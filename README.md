# 基于 S7-1200 的汽车电动车窗控制系统

> 车辆工程专业自学项目 · TIA Portal V16 · S7-1200 + PLCSIM 仿真验证

一个用于学习**车身电控逻辑设计与验证**的小项目：用西门子 S7-1200 实现车窗的上升、下降、互锁、限位、防夹与故障锁存，并在 S7-PLCSIM 中完成逐条测试。

项目重点不在"把功能做出来"，而在**把逻辑验证清楚**：每一段程序都有对应的测试用例，每一次修改都有前后对比记录。

## 2. I/O 分配

### 数字量输入

| 地址 | 名称 | 说明 |
|---|---|---|
| %I0.0 | 上升按钮 | 控制车窗上升 |
| %I0.1 | 下降按钮 | 控制车窗下降 |
| %I0.2 | 上限位 | 车窗到顶停止 |
| %I0.3 | 下限位 | 车窗到底停止 |
| %I0.4 | 防夹信号 | 遇阻反转 |
| %I0.5 | 报警复位 | 清除故障锁存 |

### 数字量输出

| 地址 | 名称 | 说明 |
|---|---|---|
| %Q0.0 | 电机正转 | 车窗上升 |
| %Q0.1 | 电机反转 | 车窗下降 |
| %Q0.2 | 报警 | 防夹/故障指示 |

### 中间变量

| 地址 | 名称 | 说明 |
|---|---|---|
| %M0.2 | 故障锁存 | 防夹触发后锁存，需人工复位 |

## 3. 控制逻辑

### 程序结构（5 段）

| 段号 | 名称 | 作用 |
|---|---|---|
| 1 | 故障置位 | 防夹触发时锁存故障 |
| 2 | 车窗上升 | 上升自锁 + 互锁 + 限位 + 防夹 + 故障封锁 |
| 3 | 车窗下降 | 下降自锁 + 互锁 + 限位 + 故障封锁 |
| 4 | 报警输出 | 故障 → 报警 |
| 5 | 故障复位 | 人工复位清除故障 |

### 逻辑表达式

```
段1：I0.4 ∧ (Q0.0 ∨ Q0.1)          → (S) M0.2
段2：(I0.0 ∨ Q0.0) ∧ ¬I0.1 ∧ ¬I0.2 ∧ ¬I0.4 ∧ ¬M0.2  → Q0.0
段3：(I0.1 ∨ Q0.1) ∧ ¬I0.0 ∧ ¬I0.3 ∧ ¬M0.2          → Q0.1
段4：M0.2                            → Q0.2
段5：I0.5                            → (R) M0.2
```

### 两个设计要点

**① 自锁支路的位置**

自锁触点 `Q0.0` 并联在启动按钮 `I0.0` 两端，限位与防夹串联在自锁环**之后**。
这样无论电机是刚启动还是处于自锁保持状态，限位一动作，回路必然断开。

**② 防夹只在运行时判断**

段 1 的条件中带有 `(Q0.0 ∨ Q0.1)`，即只有电机运行时才采信防夹信号。
静止状态下的传感器信号不参与判断，避免误触发。

## 4. 版本演进

| 版本 | 内容 | 问题 |
|---|---|---|
| **v1** | 3 段：上升、下降、报警。无中间变量，防夹直接串在回路里 | 防夹信号释放后电机会自动恢复；无故障记忆 |
| **v2** | 5 段：新增 `M0.2` 故障锁存 + 置位/复位段；报警改由故障位驱动 | 已解决上电自动恢复问题 |

### v1 → v2 的核心改动

v1 中防夹只是"串在回路里的一个常闭触点"：

- 防夹来了 → 回路断开
- 防夹走了 → 回路重新闭合，**电机自动接着上升**

这在实车上是危险的：夹到物体 → 松开 → 继续夹，反复动作。

v2 引入故障锁存：防夹触发后置位 `M0.2`，只有人工按复位才能清除，期间所有输出被封锁。

## 5. 已实现的安全机制

- **自锁**：松开按钮后保持运行
- **互锁**：上升与下降互斥，同时按下不动作
- **到位停止**：上/下限位切断对应方向输出
- **防夹保护**：运动中检测到防夹信号立即停止
- **故障锁存**：故障状态保持，需人工复位
- **复位后可恢复**：排除故障并按复位后，可重新操作

| 场景 | v1 | v2 |
