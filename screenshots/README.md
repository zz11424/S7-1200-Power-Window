## v3（防夹滤波 + 反向回弹）

TIA 窗口上方为梯形图在线监视，下方为监控表，一张图同时给出"程序状态"和"信号数值"。

| 场景 | 文件 | 关键证据 |
|---|---|---|
| 上升启动 | [07_v3_上升](07_v3_上升.png) | `I0.0=1`、`Q0.0=1`、`M0.2=0` |
| 防夹确认 | [08_v3_防夹确认](08_v3_防夹确认.png) | `I0.4=1`、`M0.2=1`、`Q0.0=0`、`Q0.2=1` |
| 同上（监控表） | [08_v3_防夹确认_监控表](08_v3_防夹确认_监控表.png) | 单独截取的监控表 |
| **反向回弹** ★ | [09_v3_回弹](09_v3_回弹.png) | `Q0.1=1` 且 `M0.2=1`，回弹支路导通 |
| 故障锁存 | [10_v3_锁存](10_v3_锁存.png) | 撤除防夹后再给启动信号，输出无反应 |
| 复位 | [11_v3_复位](11_v3_复位.png) | `I0.5=1` → `M0.2=0`、`Q0.2=0` |
| 滤波 · 短脉冲不动作 ★ | [12_v3_滤波_短](12_v3_滤波_短.png) | 信号保持 3 s（阈值临时放大到 10 s），`M0.2` 仍为 0 |
| 滤波 · 持续触发 | [13_v3_滤波_长](13_v3_滤波_长.png) | 超过阈值后 `M0.2=1`、`Q0.0=0` |

> 12 / 13 两张是**成对证据**：短的不动作、长的动作，才能证明"滤波"而不是"没反应"。
> 为使 0.8 s 的回弹在截图中可见，拍摄时曾把 `DB_回弹` 的 PT 临时放大，截完已改回 800 ms。
