# 测试截图

本目录存放 v2 改造后的验证截图，共 18 张：每个场景一张监控表 + 两张梯形图在线监视。

命名规则：`序号_场景_类型.png`

- **监控表**：关键信号的实际值，是判定通过/不通过的依据
- **梯形图1 / 梯形图2**：Main [OB1] 的在线监视，绿线=导通，蓝色虚线=断开

| 场景 | 监控表 | 梯形图 |
|---|---|---|
| 01 初始状态 | [监控表](01_初始状态_监控表.png) | [图1](01_初始状态_梯形图1.png) · [图2](01_初始状态_梯形图2.png) |
| 02 上升启动 | [监控表](02_上升启动_监控表.png) | [图1](02_上升启动_梯形图1.png) · [图2](02_上升启动_梯形图2.png) |
| 03 防夹触发 | [监控表](03_防夹触发_监控表.png) | [图1](03_防夹触发_梯形图1.png) · [图2](03_防夹触发_梯形图2.png) |
| 04 防夹释放（锁存）★ | [监控表](04_防夹释放_锁存_监控表.png) | [图1](04_防夹释放_锁存_梯形图1.png) · [图2](04_防夹释放_锁存_梯形图2.png) |

| 06 复位后可再操作 | [监控表](06_复位后可再操作_监控表.png) | [图1](06_复位后可再操作_梯形图1.png) · [图2](06_复位后可再操作_梯形图2.png) |

> 改造前同样动作下电机会自动恢复，这一张就是 v1 与 v2 的分界线。

## 环境

截图取自 TIA Portal V16 + S7-PLCSIM V16，CPU 1214C DC/DC/DC，1920×1080。
